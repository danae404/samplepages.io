MediaSession call-to-action manual test

Checking support for metadata.callToActionLabel…

1. Video

Pick a local video file (any format the browser can play), then press Play. The video needs to actually be playing for it to become the page's "controls manager" media element — that's a prerequisite for any of this plumbing to fire.

2. Metadata (whole-object replacement)

Exercises MediaSession::setMetadata() → notifyMetadataObservers().

3. Metadata (in-place mutation)

Exercises MediaMetadata::setCallToActionLabel() → metadataUpdated() → MediaSession::metadataUpdated() — a different code path than section 2, requires metadata to already be set first.

4. Action handler

Exercises MediaSession::setActionHandler(), which throws a TypeError if the experimental feature above isn't enabled.
